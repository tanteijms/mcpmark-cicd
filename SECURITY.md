# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it to us responsibly. We take security seriously and appreciate your efforts to disclose vulnerabilities in a responsible manner.

Please contact us at tanteijms@bupt.edu.cn with details about the vulnerability, including:

- Type of vulnerability
- Location in the code
- Potential impact
- Steps to reproduce

We will acknowledge your report within 48 hours and work with you to address and fix the issue as quickly as possible.
